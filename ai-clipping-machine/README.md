# AI Clipping Machine

Turn one long YouTube video into ready-to-post reels with Claude Code.

Tutorial: [Claude + YouTube = Unlimited Short Form Content](https://www.youtube.com/watch?v=UxRxeNNwzxA)

## You need
- A Mac
- Claude, Pro plan or higher (use Claude Code in the desktop app)
- An OpenAI API key with about $5 in credits
- An ElevenLabs API key (free plan works)
- Zernio to auto-post (free, optional)

## Steps
1. Open this folder in Claude Code and type **Set me up**.
2. Paste your OpenAI and ElevenLabs keys into the file that opens, save it, and tell Claude **done**.
3. Send **Clip this video: <YouTube link>**, then pick the clips you want.
4. Open the review page Claude gives you, mark each reel, and paste the feedback back into Claude.
5. Connect Zernio (**+**, **Connectors**, **Zernio**) and tell Claude which reels to schedule.
6. Optional: have Claude check your channel every week. The prompt is in [prompts.md](prompts.md).

Never paste your API keys into the chat.
